# AulaCAD 3D y Editor HTML

Herramientas para las clases de Tecnología. No necesitan cuenta ni instalación y funcionan en Chromebook y Linux.

- **AulaCAD 3D** — editor 3D al estilo Tinkercad que exporta STL para la impresora 3D: https://jsalsal003.github.io/aulacad/
- **Editor HTML** — escribe páginas web y mira el resultado al momento; avisa de etiquetas mal cerradas: https://jsalsal003.github.io/aulacad/editor-html/

Portada con las dos herramientas: https://jsalsal003.github.io/
