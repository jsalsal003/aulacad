# AulaCAD 3D

Editor 3D al estilo Tinkercad que exporta STL para la impresora 3D: **https://jsalsal003.github.io/aulacad/**. No necesita cuenta ni instalación y funciona en Chromebook y Linux.

Las demás herramientas del Taller Virtual (Editor HTML, Vistas 3D, Placa virtual, Plano 2D y Casa 3D) están ahora en la raíz de la web: **https://jsalsal003.github.io/**. Las carpetas `editor-html/`, `vistas/`, `robotica/`, `plano/` y `casa3d/` de este repositorio solo llevan a sus direcciones nuevas, para que sigan funcionando los enlaces antiguos y los QR de los desafíos.
